## [0.4.0] - 2026-09-11

### Добавлено
- **Время жизни артефактов (TTL)**: теперь у артефактов можно задать срок жизни. Суперадмин задаёт в `/admin/settings` максимальное время жизни артефакта на весь инстанс (в минутах; по умолчанию без ограничений) — оно же служит сроком по умолчанию для новых артефактов. Владельцы/админы команды могут задать своё, более строгое ограничение для своей команды, но не мягче инстанс-лимита. При создании (CLI `oa push --lifetime`, веб-интерфейс, поле `lifetime` в REST/MCP API) можно выбрать любой срок в рамках действующего лимита, а также изменить его позже через `PATCH`. По истечении срока содержимое артефакта удаляется безвозвратно (все версии удаляются без возможности восстановления) — остаётся только запись-«надгробие» для аудита и аналитики. Фактическое удаление выполняет фоновая задача (`ARTIFACT_PURGE_INTERVAL_MINUTES`, по умолчанию 5 минут); при чтении просроченный артефакт считается недоступным немедленно, независимо от того, добралась ли до него фоновая задача.

### Изменено
- Уменьшение максимального срока (инстанса или команды) пересчитывает срок жизни уже существующих артефактов от их даты создания (`min(текущий срок, дата создания + новый максимум)`) и может привести к немедленному истечению уже созданных артефактов; увеличение максимума никогда не продлевает уже созданные артефакты.
- `GET /artifacts` и `GET /artifacts/:id` теперь скрывают/возвращают 404 для артефакта с истёкшим сроком жизни, даже до того, как до него доберётся фоновая задача. В данные артефакта добавлено поле `expiresAt`.

## [0.3.0] - 2026-09-11

### Добавлено
- **Личные (привязанные к пользователю) API-ключи**: `oa login` теперь по умолчанию выпускает личный ключ — один вход, действующий во всех ваших командах с вашей реальной ролью в каждой, вместо отдельного ключа агента на команду. `oa orgs` показывает ваши команды и текущую выбранную; `oa use <team>` задаёт команду по умолчанию для текущего проекта (записывается в `.oa.json` без секретов, можно коммитить) или `--global` для всего компьютера. MCP-сервер получил параметр `orgId` у соответствующих инструментов и новый инструмент `list_orgs`; если команда не выбрана и их несколько, вместо угадывания возвращается структурированная ошибка `org_required` со списком. Ключи агентов (`oa login --agent`) не изменились и остаются правильным выбором для CI и узких прав. Новая страница «Настройки → Личные API-ключи» для выпуска и отзыва личных ключей в веб-интерфейсе.
- **Автосоздаваемое основное пространство**: теперь при регистрации каждому пользователю сразу создаётся личное «основное» пространство — в том числе при регистрации по ссылке-приглашению, вместе с членством в пригласившей команде — вместо приземления без единой команды.
- **Полноценный жизненный цикл приглашений**: приглашение теперь настоящая машина состояний (`pending`/`accepted`/`declined`/`revoked`) со списком, отзывом и перевыпуском; публичный превью по ссылке `/invite/:token`; и раздел «Приглашения» (`/invites`) в интерфейсе — уже зарегистрированный приглашённый видит приглашение и сам принимает или отклоняет его, без отправки почты.
- **Идентификация одноимённых команд**: единый компонент `OrgIdentity` (цветная монограмма от id, бейдж «Основное», вторая строка — владелец/slug) применяется везде, где отображается команда, плюс email владельца и счётчики участников/артефактов в каждом списке — теперь две команды (или два личных пространства) с одинаковым названием различимы.
- **Переключатель команд с поиском**: переключатель в сайдбаре теперь всплывающее окно с поиском, сгруппированное на «Основное» / «Мои команды» / (для суперадмина) «Все команды инстанса» с серверным поиском.
- **Переработанная админка**: `/admin` теперь настоящие вкладки-роуты (Обзор, Пользователи, Команды, Аудит, Настройки инстанса) вместо одного компонента на 387 строк; поиск пользователей по имени и email с настоящей пагинацией по `total` и чипами команд; аудит с keyset-пагинацией, резолвнутыми именами/email акторов и русскими подписями действий; все пять настроек инстанса теперь редактируются (раньше — только режим регистрации).
- **Инструкции для агентов — всем пользователям**: шпаргалка по подключению агентов переехала из `/admin/instructions` в `/help/agents`, доступна любому авторизованному — подключение агента задача команды, а не только суперадмина. Старые ссылки продолжают работать через редирект.
- **Дизайн-система на Tailwind v4**: весь веб-интерфейс переведён с рукописного CSS на Tailwind v4 и набор доступных примитивов (`Button`, `Dialog`, `ConfirmDialog`, `DropdownMenu`, `Toast`, `Table`, `EmptyState` и другие), с переключателем светлой/тёмной/системной темы и мобильным выдвижным меню — без единой новой runtime-зависимости.
- **Управление командами**: переименование команды, добавление уже зарегистрированного пользователя напрямую в команду (минуя приглашение), редактор квоты хранилища для суперадмина.

### Изменено
- **`GET /auth/me` больше не отдаёт суперадмину все команды инстанса**: теперь только собственные членства, плюс `mainOrgId` и счётчик ожидающих приглашений — до чужих команд суперадмин теперь добирается поиском. (Ломающее изменение API для внешних клиентов, ожидавших старый формат.)
- Последние оставшиеся нативные диалоги `confirm()`/`alert()`/`prompt()` заменены на полноценные модальные компоненты.

### Исправлено
- **Подмена email при регистрации по приглашению**: регистрация по ссылке больше не доверяет присланному email, если он не совпадает с адресом из приглашения — закрыта дыра, позволявшая присоединиться под произвольным адресом, зная только ссылку.
- Владельца-создателя команды можно было удалить как последнего оставшегося owner через `DELETE /orgs/:id/members/:userId` (гард стоял только на `PATCH`); теперь оба эндпоинта это запрещают, а создатель личного пространства не может покинуть его или быть из него удалён.
- Вход и регистрация больше не ведут на несуществующий маршрут `/artifacts`.

## [0.2.0] - 2026-09-11

### Добавлено
- **Сервер Model Context Protocol (MCP)**: Встроенный эндпоинт Streamable HTTP по пути `/mcp` с инструментами (`whoami`, `list_artifacts`, `get_artifact`, `create_artifact`, `update_artifact`, `delete_artifact`, `create_share`, `list_shares`, `revoke_share`) для прямого подключения Cursor, Claude Desktop, Claude Code и других LLM-клиентов.
- **Скилл для AI-агентов**: Стандартизированная спецификация навыка по формату [skills.sh](https://skills.sh/emaxe/open-artifacts) (`skills/open-artifacts/SKILL.md`), позволяющая агентам автоматически устанавливать CLI, проверять доступ и публиковать артефакты.
- **Интерактивный OAuth Device Flow**: Полноценный сценарий авторизации устройств через команду `oa login` с короткими одноразовыми кодами (`ABCD-1234`), подтверждаемыми в браузере по адресу `/activate`.
- **Мультитенантность, организации и команды**: Разделение на организации и команды, приглашение участников, управление пользователями и гибкие роли доступа (`superadmin`, `admin`, `member`).
- **Интерактивный раннер (`run.sh`)**: Скрипт для запуска Docker-контейнеров, локального окружения, тестов, сборок и миграций через удобное консольное меню.
- **Страница инструкций в интерфейсе**: Интерактивная документация и готовые команды для агентов во встроенной панели управления по адресу `/admin/instructions`.
- **Ссылки с ограничением по времени и защитой паролем**: Возможность задать срок жизни ссылки (`--expires 1h/1d/7d/30d`) и пароль для доступа (`--password`).
- **Двуязычная документация**: Полные версии README и списков изменений (Changelog) на русском и английском языках, бейджи и теги в GitHub.

### Изменено
- **Переименование пакета CLI**: Пакет консольной утилиты переименован в [`@emaxe/oa`](https://www.npmjs.com/package/@emaxe/oa) в реестре npm.
- **Улучшение переключателя команд**: Компонент Team Switcher теперь отображает понятные названия команд и предоставляет суперпользователю прозрачный доступ ко всем организациям системы.

### Исправлено
- Исправлена работа TypeScript при включенном флаге `noUncheckedIndexedAccess` в подсчете записей в API.
- Устранена рассинхронизация названий команд при переключении между профилями.

## [0.1.0] - 2026-09-10

### Добавлено
- Начальный публичный релиз Open Artifacts:
  - Автономный хостинг артефактов для AI-агентов.
  - Изолированный рендеринг в безопасной песочнице `<iframe>` для HTML, Markdown, Mermaid и SVG.
  - REST API на базе Hono и PostgreSQL (Drizzle ORM).
  - Веб-интерфейс на React + Vite для администраторов и пользователей.
  - Базовая утилита командной строки `oa`.
  - Развертывание стека в один клик через Docker Compose.
